# Frontend UI & Design Rules

Apply these rules for all frontend work under `apps/fe/`:

- Follow `.agents/skills/frontend-design/SKILL.md` for visual hierarchy, Tailwind CSS styling, `lucide-react` icons, and optional `three` accents.
- Use a crisp **white and cobalt-blue** palette (`#FFFFFF`, `#F8FAFC`, `#E2E8F0`, `#0F172A`, `#2563EB`). Avoid generic purple/neon gradients, heavy shadows, and emoji icons.
- Keep forms, tables, and timetable layouts clean, responsive, and accessible (proper `<label>`, focus rings, clear error/empty states, and `prefers-reduced-motion` respect).
